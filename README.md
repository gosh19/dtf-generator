# DTF Generator

Herramienta web para procesamiento y preparación de archivos para impresión DTF (.AI, .SVG y .PNG a PDF con canales spot/tinta blanca).

## Características

- Soporte para archivos `.AI` (Adobe Illustrator), `.SVG` y `.PNG`.
- Procesamiento en el navegador con descompresión y parseo de capas/vectores.
- Generación de archivos PDF listos para impresión DTF con tintas directas/blanco spot.
- Control de resolución (300 DPI), dimensiones y perfiles ICC.

## Uso

Abre `index.html` en un navegador web moderno o utiliza el ejecutable directo `GeneradorDTF.exe`.
